# Import

### Audio

Launches a file selection window where you can choose to _import_ one or more audio files _into_ the current Audacity project. The file(s) will always be added as a new track to the project. This lets you mix two or more files together.

See [Importing Audio](https://manual.audacityteam.org/man/importing_audio.html) for more information.
