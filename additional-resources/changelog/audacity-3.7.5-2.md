This is a hotfix release. It fixes the following bugs:

* [#10033](https://github.com/audacity/audacity/issues/10033), [#10011](https://github.com/audacity/audacity/issues/10011) Fixed broken waveform scrolling and selection for some users introduced in 3.7.6
