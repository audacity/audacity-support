# Audacity 3.7.6

This is a patch release. It contains the following changes:

* [#9742](https://github.com/audacity/audacity/issues/9742) Added FFmpeg 8 support
* [#9709](https://github.com/audacity/audacity/issues/9709) Added Spectrogram Wavelet analysis (Thanks, Klaus Gram-Hansen (@kgramhans))
* [#9565](https://github.com/audacity/audacity/issues/9565) Added middle-mouse drag panning over track panel (Thanks, Anders Jenbo (@AJenbo))
* [#9863](https://github.com/audacity/audacity/issues/9863) Added "Import from audio.com" dialog to import audio files from audio.com
* [#9838](https://github.com/audacity/audacity/issues/9838) Fixed unstable cloud audio uploads
* [#9576](https://github.com/audacity/audacity/issues/9576) Allowed export as OGG/Opus when exporting with FFmpeg
* [#9929](https://github.com/audacity/audacity/issues/9929) Fixed 16-bit FLAC import
* [#9897](https://github.com/audacity/audacity/issues/9897) Library updates: libcurl to 8.17.0, wavpack to 5.7.0
